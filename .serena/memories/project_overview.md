# Project Overview

## Purpose
haru's personal dotfiles repository. Targets macOS (Apple silicon; Homebrew paths hardcoded to
`/opt/homebrew`) and Linux (including WSL2). Installation is driven by `make` / `install.sh`,
which symlinks config files from `dotfiles/` into `~`, copies the Prezto runcoms into
`~/.zprezto`, and symlinks scripts from `bin/` (and optional `private_bin/`) into `~/bin`.

## Tech stack
- **Primary language**: Shell (POSIX `sh` preferred; `bash` only when necessary — e.g., `install.sh`).
- **Shell config**: zsh + Prezto (`dotfiles/zprezto/`), asdf (shims on `PATH`), Homebrew on both
  macOS and Linux. See the `zsh_config` memory.
- **Tooling layer**: Node.js (`^22.20.0`) + npm (`^11.6.1`) for lint orchestration only — no runtime code.
- **External CLIs required for dev**: `gibo` (`^2.2.7`), `vale` (`^2.20.1`), `yamllint` (`^1.27.1`),
  `shellcheck` (`>=0.8.0 <1.0.0`).
- **Dev deps (npm)**: `commitlint` + `commitizen` (Conventional Commits),
  `husky` (git hooks), `lint-staged`, `markdownlint-cli`, `prettier`, `secretlint`,
  `npm-run-all`, `npm-check-updates`.

## Repo layout (top level)
- `install.sh` — bash installer (see the `install_flow` memory).
- `get-os.sh` — prints `mac` or `linux`; exits 1 otherwise. Canonical OS detection for repo-local code.
- `Makefile` — entry point for `install`, `dev-install`, `lint*`, `update-gi*`.
- `dotfiles/` — top-level regular files are symlinked into `$HOME` (`.gitconfig`,
  `.gitconfig_personal`, `.gitignore_global*`, `.tmux.conf`, `.vimrc`, `.asdfrc`).
  Subdirs `zprezto/`, `etc/`, `wsl/` are special-cased.
- `bin/` — shell scripts symlinked into `~/bin` without `.sh` suffix. `bin/linux/` is Linux-only.
- `private_bin` — optional, gitignored symlink to a user-private directory; installed like `bin/`.
- `.gitignore`, `dotfiles/.gitignore_global*` — GENERATED by `gibo`; edit the `*_custom` prefix files.
- CI/config: `.github/`, `.husky/`, `.vscode/`, `.serena/`, `.claude/`, various lint dotfiles.

## Key design points
- No test suite; `npm test` intentionally exits 1.
- OS detection: repo-local code (`install.sh`) uses `get-os.sh`. Code that runs outside the repo
  (`bin/*.sh` via `~/bin`, the copied zsh runcoms) can't locate it and inlines the same
  `case $(uname)` switch (`Darwin` → `mac`, `Linux` → `linux`).
- `install.sh` iterates only regular files in `dotfiles/` top level; subdirs are handled by
  explicit special cases in the script.
- Known TODO in `install.sh`: the Linux branch assumes WSL2 without checking.
- `make lint-sh` silently skips top-level `bin/*.sh` (glob gotcha; see `suggested_commands`).
- `.gitconfig` includes `.gitconfig_personal` for repos under `~/workspace/haru52/`, which switches
  the global excludes file to `.gitignore_global_personal`. Unlike `.gitignore_global`, it does
  not ignore `.serena/`, so this repo tracks `.serena/project.yml` and these memories.
- `CLAUDE.md` covers the same ground as these memories; keep both in sync.
